02 / Inventory query

Filter with intent.

Query names are case-insensitive. Omit any filter you do not need. Multiple supplied filters are combined.

04 / Operating rules

Ship safely.

The API is deliberately read-only. Treat response shapes as versioned contracts and move breaking changes to a future API version.

HTTPS only

Production clients and Meta should use the secure API base URL displayed above.

JSON vs. CSV

Application endpoints return JSON. Only the Meta vehicle-feed endpoint returns CSV.

Meta eligibility

Feed rows require stock, VIN, positive price, and at least one real vehicle image.

Read-only API

All documented operations use GET and do not modify inventory records.

Error handling

Validate HTTP status codes. Inventory failures return 500; invalid queries return 400.

Version boundary

Build new incompatible contracts under /api/v2 rather than changing v1 clients silently.
